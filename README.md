# TPI 2 - Integración Backend y Frontend

## Descripción:

Aplicación en React con Vite que funciona como frontend del Trabajo Práctico Integrador N° I (Sistema de Gestión de Blog Personal con Autenticación), junto con Tailwind CSS para la presentación visual.

### Tecnologías:

### Backend

- Json Web Token JWT
- Cookie-parser
- Bcrypt
- Express-validator
- Sequelize
- Cors

### Frontend

- React
- Vite
- Tailwind Css

**Materia:** Taller de Lenguaje de Programación II
**Año:** 2026
